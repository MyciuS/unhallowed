# UML diagrams

MagicDraw exports live here (requirement 14). Two per defended pattern:

```
NN-<key>-before.png
NN-<key>-after.png
```

For example `09-decorator-before.png` and `09-decorator-after.png`, referenced from
`docs/patterns/09-decorator.md`.

## Requirements

- Exported from MagicDraw, not drawn by hand or screenshotted from an IDE
- Classes tidily arranged, no crossing lines where it can be avoided, no clipped labels
- PNG at a readable resolution
- GoF role names labelled on the "after" diagram (Context, Strategy, ConcreteStrategy, ...) so the
  mapping between the book and our code is obvious

Keep the `.mdzip` project file in this folder too, so the diagrams can be edited during a defence
if the lecturer asks for a change (requirement 13).
